# Information Security Policy

## Overview
Acme Corp maintains strict information security standards to protect company data and ensure compliance with Indian regulations. All employees must follow these guidelines when handling company information, regardless of location or device used.

## Data Classification
Company data is categorized into four classes:
• **Public**: General information available to anyone (e.g., press releases)
• **Internal**: Company-specific data not for public disclosure (e.g., internal memos)
• **Confidential**: Sensitive business information (e.g., financial data, strategic plans)
• **Restricted**: Highly sensitive data requiring special handling (e.g., employee records, source code)

## Security Requirements
All employees must:
• Lock computer screens when stepping away from workstations
• Use GlobalProtect VPN when connecting to company resources on public Wi-Fi networks
• Never store work files on personal cloud storage services
• Report suspected security incidents within 1 hour to security@acme.example (treated as P1 priority)
• Report phishing emails using the built-in report button in email clients

## Device and Access Controls
• USB storage devices are blocked on all company computers
• All accounts require MFA using Okta Verify
• Passwords must be at least 14 characters long with mixed case, numbers, and symbols
• IT support staff will never ask for your password under any circumstances
• Software requests must be submitted through Jira IT ticketing system (type: Software Request)

## Incident Response
In case of suspected security incidents, immediately notify security@acme.example. All reported incidents are treated as P1 priority requiring immediate response. Do not attempt to investigate or resolve security issues independently.

## Compliance
This policy applies to all employees, contractors, and third parties with access to company information systems. Non-compliance may result in disciplinary action including termination.

# Approved Software Catalog

## Overview
This document outlines the approved software tools for Acme Corp employees. All software must be sourced through approved channels to ensure security, compliance, and support.

## Approved Tools
The following tools are officially approved for use:
• Slack - Communication platform
• Zoom - Video conferencing
• Google Workspace - Productivity suite
• Jira - Project management
• Confluence - Documentation
• GitHub - Code repository
• 1Password - Password management
• Okta Verify - Multi-factor authentication
• GlobalProtect - VPN service
• Docker Desktop - Containerization
• VS Code - Code editor

## Licensing and Approval
• JetBrains IDEs require manager approval before installation
• All software must be properly licensed through Acme Corp channels
• Unapproved tools are strictly prohibited

## Usage Guidelines
• Employees may use approved tools for work-related activities only
• Unauthorized software installations are not permitted
• Any additional software requests must be submitted via Jira IT Software Request ticket (type: "Software Request")
• Torrent clients and unapproved file-sharing services are strictly forbidden

## Support and Maintenance
• All approved tools receive standard support through IT department
• Software updates follow company security protocols
• Security patches are applied automatically where possible

## Compliance
This catalog is maintained by IT and reviewed quarterly. Any changes require formal approval from the IT Director. Employees must report unauthorized software usage immediately to it-help@acme.example.
